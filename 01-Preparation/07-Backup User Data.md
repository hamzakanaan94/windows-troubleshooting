# Backup User Data

## Overview

Customer data is more valuable than the operating system itself.

Windows can always be reinstalled, but personal files, work documents, photos, and memories may be impossible to recover if they are lost.

Before formatting any device, I make sure that important customer data is identified, backed up, and verified.

Protecting customer data is one of the highest priorities throughout the entire service process.

---

# Objectives

- Prevent accidental data loss.
- Protect customer files.
- Verify backup integrity.
- Preserve important accounts and settings.
- Respect customer privacy.
- Minimize risks before formatting.

---

# Confirm Customer Requirements

Before creating a backup, I ask the customer which files and information are important.

Examples include:

- Photos
- Videos
- Documents
- Work files
- Projects
- Downloads
- Desktop files
- Personal folders

I never assume that a file is unimportant.

---

# Verify Drive Health

Before copying any data, verify the storage device.

Check:

- SMART Status
- Drive Health
- Bad Sectors
- Read Errors

If the drive shows signs of failure, important files should be copied immediately before performing any other operation.

---

# Accounts and Synchronization

Before formatting the computer, verify that important accounts are properly synchronized.

Examples:

- Google Account
- Microsoft Account
- OneDrive
- Google Drive
- Browser Synchronization
- Email Accounts

Also verify:

- Browser Bookmarks
- Saved Passwords
- Browser Extensions
- Email Configuration
- Cloud Synchronization Status

This helps prevent accidental loss of important information after Windows installation.

---

# Applications

Review any important applications that the customer expects to use after Windows installation.

Examples:

- Microsoft Office
- AutoCAD
- Adobe Applications
- Programming Tools
- Accounting Software
- Professional Software

Confirm whether application settings or local data require backup before formatting.

---

# Local Application Data

Some applications store important information locally.

Examples:

- WhatsApp Desktop
- Telegram Desktop
- Outlook
- Thunderbird
- Other applications with local databases

Review these applications with the customer before proceeding.

---

# Backup Location

Backup destination should always be chosen together with the customer.

Possible options include:

- External Hard Drive (Preferred)
- USB Flash Drive
- Memory Card
- Another Internal Drive
- Cloud Storage (when sufficient space is available)

The backup method depends on the customer's preference and available resources.

---

# Customer Confirmation

If the customer believes that nothing important is stored on the computer, I always confirm this again.

I specifically ask about:

- Photos
- Videos
- Documents
- Downloads
- Work Files
- Personal Projects
- Browser Data
- Application Data

Only after receiving confirmation do I continue with the installation process.

---

# Backup Verification

After copying the files, the customer should verify that everything important has been backed up successfully before formatting begins.

This additional confirmation helps prevent misunderstandings and accidental data loss.

---

# Privacy and Confidentiality

Customer privacy is a fundamental professional responsibility.

I never browse, open, or inspect personal files during the backup process unless the customer explicitly requests assistance with a specific file.

The backup process copies customer data without accessing its contents.

Respecting privacy is a non-negotiable part of my work.

---

# Backup Security

When appropriate, backup data may be stored on an encrypted storage device.

The encryption password should always remain under the customer's control.

After the customer confirms that the new system is working correctly and all required files have been restored, any temporary backup copies under my responsibility are securely removed.

---

# Technician Philosophy

Backing up customer data is not simply another installation step.

It is the customer's trust.

A successful Windows installation means very little if important personal data is lost.

My goal is to ensure that every customer receives their computer with both the operating system and their personal information safely preserved.

---

# Checklist

- Customer interviewed
- Important files identified
- Drive health verified
- Accounts synchronized
- Browser data confirmed
- Applications reviewed
- Local application data checked
- Backup destination selected
- Backup completed
- Customer verified backup
- Privacy respected
- Backup secured
- Ready for Windows installation
