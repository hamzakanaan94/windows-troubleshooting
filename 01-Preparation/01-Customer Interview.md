# Customer Interview

## Overview

Before performing any diagnostic, repair, or Windows installation, I always begin by talking to the customer. This helps identify the actual problem, understand the customer's expectations, and prevent data loss or unnecessary work.

---

## Objectives

- Understand the customer's issue.
- Determine whether Windows installation is necessary.
- Identify important user data.
- Confirm requested software and configuration.
- Explain the repair process.

---

## Questions to Ask

### General Information

- What is the main problem?
- When did the problem start?
- Did anything happen before the issue appeared?
- Has the device been repaired before?

### Data Protection

- Do you have important files?
- Have you already created a backup?
- Are there any files on the Desktop, Documents, or Downloads folders that must be saved?

### Windows Installation

- Do you want a clean installation or only system repair?
- Do you want to keep your current partitions?
- Should the entire drive be formatted?

### Software Requirements

Ask the customer about required applications, such as:

- Microsoft Office
- Google Chrome
- Adobe Acrobat Reader
- Telegram
- WhatsApp
- AutoCAD
- Specialized work software

---

## Important Notes

Never assume that the customer has backed up their files.

Always confirm this before formatting the drive.

If there is any doubt, create a backup first.

---

## Technician Checklist

- [ ] Customer problem identified
- [ ] Backup requirement confirmed
- [ ] Windows installation type selected
- [ ] Required software listed
- [ ] Customer approval received
