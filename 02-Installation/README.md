# Installation

## Overview

This section documents the complete Windows installation workflow after the preparation stage has been completed.

The objective is to perform a clean, stable, and repeatable Windows installation while minimizing configuration errors and ensuring compatibility with the target hardware.

Each document represents one stage of the installation process.

---

## Workflow

1. BIOS or UEFI Configuration
2. Installation Media Verification
3. Boot Menu
4. Disk Partitioning
5. Windows Installation
6. OOBE (Initial Windows Setup)
7. Windows Activation

---

## Prerequisites

Before starting this section, complete every step inside:

- 01-Preparation

Including:

- Customer Interview
- Device Inspection
- Disk Health Check
- BIOS or UEFI Check
- Hardware Assessment
- Windows Version Selection
- Backup User Data

---

## Expected Outcome

After completing this section:

- Windows is successfully installed.
- Initial setup (OOBE) is completed.
- Windows is activated (if applicable).
- The system is ready for post-installation configuration.

The next stage is:

**03-Configuration**
