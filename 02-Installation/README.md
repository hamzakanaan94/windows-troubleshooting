# Installation

## Overview

This section documents the complete Windows installation workflow after completing the preparation stage.

The goal of this phase is to perform a clean, stable, and hardware-compatible Windows installation while minimizing installation errors and ensuring a reliable user experience.

Each document inside this section represents one stage of the installation process, from system preparation before booting the installation media until Windows activation is completed.

---

## Workflow

The installation process follows these steps:

1. BIOS or UEFI Configuration
2. Installation Media Verification
3. Boot Menu Selection
4. Disk Partitioning
5. Windows Installation
6. OOBE (Initial Windows Setup)
7. Windows Activation

---

## Prerequisites

Before starting the installation process, all preparation steps must be completed.

Required preparation:

- Customer Interview
- Device Inspection
- Disk Health Check
- BIOS or UEFI Check
- Hardware Assessment
- Choose Windows Version
- Backup User Data

These steps ensure that the correct Windows version is selected, hardware compatibility is verified, and customer data is protected before performing any system changes.

---

## Installation Principles

The installation process follows these principles:

- Use a clean Windows installation whenever possible.
- Select the Windows version according to hardware capability and customer requirements.
- Maintain compatibility between BIOS/UEFI mode and installation media.
- Protect customer data before formatting or modifying storage.
- Avoid unnecessary changes that may affect system stability.
- Verify each stage before moving to the next step.

---

## Expected Outcome

After completing this section:

- Windows is successfully installed.
- Initial Windows setup (OOBE) is completed.
- Activation status is verified.
- The operating system is ready for the configuration stage.
