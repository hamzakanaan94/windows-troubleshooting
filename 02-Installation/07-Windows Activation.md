# Windows Activation

## Purpose

Windows Activation is the final verification step after installing Windows.

The goal is to confirm that the installed Windows copy is properly licensed and ready for normal customer use.

Activation is a simple process during normal installation. Advanced licensing problems and hardware-related activation issues are handled separately in the Troubleshooting section.

---

## Activation Process

After completing Windows installation:

1. Connect the device to the internet.
2. Open Windows Activation settings.
3. Enter the customer's valid Windows product key if available.
4. Confirm that Windows activation is completed successfully.

Activation can be performed:

- During Windows installation.
- After reaching the Windows desktop.

If the customer does not have the product key during installation:

Select:

```
I don't have a product key
```

and continue the installation.

The activation process can be completed later when a valid license is available.

---

## Activation Verification

Before moving to the next configuration stage, verify:

- Windows edition is correct.
- Activation status is successful.
- No activation warnings are displayed.
- The system is ready for normal use.

A successful Windows installation does not always mean that activation is complete, therefore activation status must always be checked.

---

## Windows Without Activation

Windows can operate without activation, but some limitations may appear.

Possible limitations include:

- Restricted personalization options.
- Activation notifications.
- Limited access to some Windows features.

For professional deployment, activating Windows with a valid license is recommended.

---

## Licensing Recommendation

Always recommend using official Windows licensing.

Official activation provides:

- System reliability.
- Access to official updates.
- Better security.
- Long-term stability.

The technician should always respect the customer's license ownership and provide a properly configured system.

---

- ✅ Correct Windows edition installed.
- ✅ Product key entered if available.
- ✅ Activation status verified.
- ✅ No activation warnings remain.
- ✅ System ready for configuration.
