# Installation Media Verification

## Overview

A successful Windows installation begins with reliable installation media.

Before booting any device, I verify that the USB drive, Windows image, and firmware compatibility are all suitable for the target system.

Using properly prepared installation media significantly reduces installation failures, boot errors, and compatibility issues.

---

# Objectives

- Verify USB installation media.
- Ensure firmware compatibility.
- Use stable Windows images.
- Prevent installation errors.
- Minimize troubleshooting during setup.

---

# Windows Image Selection

I always prefer official, unmodified Microsoft Windows images.

Clean (stock) Windows installations provide:

- Better stability
- Better security
- Better compatibility
- Improved long-term reliability
- No unnecessary software
- No unofficial modifications

The customer receives a clean operating system and installs only the applications they actually need.

---

# Windows Versions

I maintain a collection of Windows installation media for different hardware generations.

Examples include:

- Windows XP
- Windows 7
- Windows 8
- Windows 10
- Windows 11

Each version is prepared separately to ensure maximum compatibility with the target device.

---

# Stable Releases

I always use stable Windows releases.

Beta, Insider Preview, or experimental builds are never used on customer devices.

Before updating my installation media, I verify that the release has proven stability and reliability.

---

# USB Preparation

My preferred tool for creating Windows installation media is Rufus.

I use:

- Standard Windows Installation
- Official Windows ISO
- Appropriate partition scheme for the target firmware
- FAT32 whenever possible for maximum UEFI compatibility

If the Windows image exceeds FAT32 limitations, Rufus provides compatible alternatives while maintaining boot support.

---

# Installation Media Library

Rather than creating a new USB drive for every installation, I maintain a dedicated collection of prepared Windows installation drives.

Examples include:

- Windows 10 (Legacy BIOS)
- Windows 10 (UEFI)
- Windows 11

Each USB drive is tested before use and updated whenever a newer stable Windows release becomes available.

This approach saves time while maintaining consistency and reliability.

---

# Windows ISO Sources

My preferred source is Microsoft's official Windows images.

If Microsoft's servers are temporarily unavailable or downloads are unusually slow, I may use trusted mirrors that distribute the original Microsoft ISO files without modification.

Image authenticity and integrity are always verified before use.

---

# USB Capacity

A 16 GB USB drive is generally sufficient for modern Windows installation media.

Larger USB drives are only necessary when storing multiple operating systems or additional recovery tools.

---

# Verification Before Installation

Before connecting the USB drive to the customer's computer, I verify:

- Correct Windows version
- Correct Windows edition
- Stable Windows release
- Proper firmware compatibility
- Functional USB drive
- Bootable installation media

Whenever necessary, I also test the USB drive on a separate computer before using it on a customer's device.

---

# Technician Philosophy

Reliable installation media is the foundation of a successful Windows installation.

Many installation problems originate from damaged USB drives, corrupted ISO files, or incompatible boot configurations—not from Windows itself.

Taking a few minutes to verify the installation media helps prevent unnecessary troubleshooting later.

Clean installation media leads to clean installations.

---

# Checklist

- Official Windows image selected
- Stable release verified
- Correct Windows edition selected
- USB prepared successfully
- Firmware compatibility confirmed
- Bootable media verified
- USB tested (when required)
- Ready for Windows installation
