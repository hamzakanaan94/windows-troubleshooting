# OOBE (Initial Windows Setup)

## Purpose

The Out-of-Box Experience (OOBE) is the initial Windows setup process that prepares the operating system for its first use.

This stage is more than simply clicking **Next** through setup screens. Every decision made during OOBE should match the customer's requirements, privacy preferences, and intended use of the device.

The objective is to deliver a clean, properly configured operating system that is ready for long-term use while avoiding unnecessary configuration changes after installation.

---

## Internet Connection

Whenever possible, connect the device to the internet during OOBE.

An active internet connection allows Windows to:

- Verify internet connectivity.
- Synchronize the correct date and time.
- Detect the appropriate time zone.
- Complete initial Microsoft service configuration.
- Prepare Windows for future updates.

However, internet connectivity should always be considered alongside the customer's preferences.

If the customer prefers a completely local installation or does not wish to use Microsoft services, OOBE can be completed offline using a Local Account.

The chosen setup method should always reflect the customer's requirements rather than personal preference.

---

## Region & Keyboard Layout

Verify that the correct region and keyboard layout are selected.

Confirm:

- Country or region.
- Primary keyboard layout.
- Secondary keyboard layout (if required).

Additional keyboard layouts should only be installed when requested by the customer.

Avoid installing unnecessary language packs or keyboard layouts that may confuse inexperienced users.

---

## Microsoft Account vs Local Account

Account selection depends entirely on how the customer intends to use the device.

### Microsoft Account

Recommended for personal devices because it provides:

- Password synchronization.
- OneDrive integration.
- Microsoft Store access.
- Windows settings synchronization.
- License synchronization.
- Easier password recovery.

### Local Account

Recommended when:

- Maximum privacy is preferred.
- Microsoft cloud services are unnecessary.
- The computer will remain offline.
- Company policy requires local authentication.
- The customer specifically requests a local account.

Neither option is universally better.

The correct choice is the one that best matches the customer's workflow.

---

## Device Privacy Settings

Review all Windows privacy options carefully.

Examples include:

- Location Services
- Find My Device
- Advertising ID
- Diagnostic Data
- Inking & Typing Personalization
- Speech Recognition

Privacy settings should never be changed automatically without understanding their impact.

When appropriate, explain their purpose to the customer and configure them according to their preferences.

---

## OneDrive Configuration

Determine whether the customer intends to use OneDrive.

Possible scenarios include:

- Enable full OneDrive synchronization.
- Synchronize Desktop, Documents, and Pictures.
- Disable automatic folder backup.
- Skip OneDrive entirely.

Customers who already rely on Microsoft's cloud ecosystem usually benefit from OneDrive.

Customers who prefer complete local storage may choose not to use it.

---

## Microsoft Services

Windows may offer additional Microsoft services during OOBE.

Examples include:

- Microsoft 365 trial
- Microsoft Backup
- Xbox services
- Game Pass
- Copilot (depending on Windows version)

These options should only be accepted when they provide value to the customer.

Avoid enabling unnecessary services that increase background activity or complicate the user's experience.

---

## Initial User Configuration

Complete any remaining setup options according to the customer's requirements.

Examples include:

- Device usage preferences (if presented).
- Automatic backup options.
- Synchronization preferences.
- Personalization options.

Keep the initial configuration as simple and clean as possible.

Additional customization can always be performed after Windows installation.

---

## OOBE Completion

After Windows reaches the desktop:

- Allow the operating system approximately one to two minutes to complete its background initialization.
- Wait for Windows Services to finish loading.
- Allow Microsoft Defender to initialize.
- Allow indexing and scheduled startup tasks to complete.

Do not begin installing software immediately after the desktop appears.

Waiting briefly results in a more stable environment for the next configuration stage.

---

## Summary Checklist

- ✅ Internet connection configured appropriately.
- ✅ Region verified.
- ✅ Keyboard layout verified.
- ✅ Microsoft or Local Account selected according to customer requirements.
- ✅ Privacy settings reviewed.
- ✅ OneDrive configured appropriately.
- ✅ Unnecessary Microsoft services skipped.
- ✅ Windows reached the desktop successfully.
- ✅ Initial background tasks completed.
- ✅ Ready for Windows Activation.
